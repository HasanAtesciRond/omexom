## Documentation Standards

- **Language:** Dutch for user-facing content, English for technical specs
- **Format:** Markdown (.md)
- **Updates:** Keep in sync with code changes
- **Version:** Document version noted in each file

## Contributing

When updating documentation:
1. Update the relevant .md file
2. Keep examples current
3. Update screenshots if UI changes
4. Maintain consistent formatting
